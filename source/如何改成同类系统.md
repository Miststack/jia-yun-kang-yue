# 如何改成同类监测系统

把本仓库当成模板：改一份配置，就能换成另一套名称、单位、阈值和预警文案，不必先改 `index.html`。

当前默认值对应 **甲韵康跃 · 监测与预警系统**（肌电 μV、喉返神经）。

## 1. 最短步骤

1. 打开 `source/app/config.json`（每段都有「说明」字段，按注释改即可）
2. 至少改这三项：
   - `branding.short_name`、`logo_title`：你的产品名
   - `branding.installer_id`：新的 GUID（见下文）
   - `labels` / `alert`：卡片标题和预警句子
3. 双击 `启动监测系统.bat` 预览
4. 确认后再双击 `打包成EXE.bat`、`生成安装包.bat`

启动和打包脚本都会自动运行 `apply_config.py`，把 json 同步到界面和安装包名称。

## 2. 必须换卸载 ID

同类新产品务必改 `branding.installer_id`，否则会和甲韵康跃抢同一个「卸载」项。

PowerShell 生成：

```powershell
[guid]::NewGuid().ToString()
```

填成：

```text
{xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx}
```

## 3. 字段说明

### branding（名称与单位）

| 字段 | 作用 |
|------|------|
| `app_name` | 窗口标题栏完整名称 |
| `short_name` | exe、开始菜单、安装包文件名（不要特殊符号） |
| `logo_title` | 界面左上角大字 |
| `logo_subtitle` | 界面左上角小字 |
| `publisher` | 安装包里的发布者 |
| `version` | 版本号，会写入安装包 |
| `unit` | 数值单位。肌电 `μV`，压力 `mmHg`，温度 `℃` |
| `anatomy_label` | 热力图中央部位名称，如「喉返神经」 |
| `installer_id` | Windows 卸载 GUID，新产品必换 |

### baseline（基线学习）

| 字段 | 作用 |
|------|------|
| `learn_count` | 学基线用多少个有效点（默认 20） |
| `valid_min` / `valid_max` | 学习阶段合法范围，超出提示电极异常且不计入 |
| `trim_each_end` | 排序后两端各丢掉几个再平均（默认 2） |
| `warn_multiplier` | 警戒线 = 基线 × 此值（默认 4） |
| `danger_multiplier` | 危险线 = 基线 × 此值（默认 6） |
| `default_warn` / `default_danger` | 还没学成时的默认警戒 / 危险 |
| `clamp_warn_min` / `clamp_warn_max` | 警戒线允许的上下限 |
| `clamp_danger_min` / `clamp_danger_max` | 危险线允许的上下限 |

### alert（预警文案）

判定顺序：危险 → 警戒 → 趋势预判 → 安全。

模板可用占位符：`{risk}` `{safe}` `{baseline}` `{slope}` `{unit}`。

| 字段 | 作用 |
|------|------|
| `slope_threshold` | 斜率大于此值判趋势预判 |
| `slope_lookback` | 用最近几个点算斜率 |
| `danger_title` 等 | 卡片上的等级名称 |
| `danger_template` | 红色预警条 |
| `warn_template` | 黄色预警条 |
| `trend_template` | 蓝色预警条 |
| `safe_text` | 绿色时的提示 |

### labels（界面标题）

改这里就能把「肌电」换成「压力」，不必改网页代码。

| 字段 | 出现位置 |
|------|----------|
| `current_value` | 第一张卡片 |
| `slope` | 第二张卡片 |
| `risk_level` | 第三张卡片 |
| `packet_count` | 第四张卡片 |
| `baseline` | 第五张卡片 |
| `heatmap` | 左图标题 |
| `waveform` | 右图标题 |
| `slope_chart` | 下方斜率图标题 |
| `serial_title` / `serial_hint` | 串口弹窗 |
| `footer_interval` | 底栏更新频率，`{interval}` 会换成毫秒数 |
| `footer_hint` | 底栏基线提示，`{count}` 会换成学习点数 |
| `duration` / `peak` / `valley` / `clock` / `rate` | 第二排统计卡片 |
| `event_log` / `event_empty` | 预警事件列表 |
| `mute_on` / `mute_off` / `export` / `pin_on` / `pin_off` | 静音、导出、置顶按钮 |
| `pause_banner` / `stale_text` / `export_empty` / `help_title` | 暂停条、串口中断、空导出、快捷键标题 |
| `case_id` / `note` / `volume` / `marker` / `screenshot` / `records_folder` | 记录条上的文字 |
| `large_on` / `large_off` / `quick_connect` / `since_alert` | 大字、上次串口、距上次预警 |

### ui（界面辅助，不改算法）

| 字段 | 作用 |
|------|------|
| `confirm_reset` | 点重置前是否确认（演示建议 false） |
| `confirm_relearn` | 点重学前是否确认（默认 true） |
| `stale_ms` | 串口多少毫秒没数据算中断，0 关闭 |
| `rate_window_s` | 刷新率按最近几秒估算 |
| `on_top_default` | 启动时窗口是否置顶 |
| `show_threshold_lines` | 波形上是否画警戒 / 危险 / 基线 |
| `auto_save_on_close` / `auto_save_minutes` | 关闭时保存、定时保存间隔 |
| `confirm_close` | 关闭前是否再确认 |
| `large_ui_default` | 启动是否大字 |
| `remember_window` | 是否记住窗口大小 |

### 其余

| 区块 | 作用 |
|------|------|
| `window` | 窗口宽高、最小尺寸、背景色 |
| `display` | 波形保留点数、热力图格子、Y 轴上限、显示夹紧范围 |
| `simulation` | 无设备演示：刷新间隔、抬升概率、预设曲线 |
| `serial` | 默认波特率、轮询间隔、可选波特率列表 |
| `alarm` | 红/黄提示音的频率、间隔和默认音量 |
| `ui` | 确认框、串口中断、阈值线、自动存档、大字、记住窗口 |

## 4. 不要改错的文件

| 文件 | 何时改 |
|------|--------|
| **`app/config.json`** | 日常改名称、单位、阈值、文案 |
| `config.js` | **不要手改**，启动时会覆盖 |
| `index.html` | 只有新增按钮、新图时才需要 |
| `installer/*.iss` 的 `[Messages]` | 想改安装向导欢迎语时 |
| `apply_config.py` | 一般不用动 |

## 5. 示例：改成术中压力监测

在 `config.json` 里改成类似：

```json
"logo_title": "术中压力",
"logo_subtitle": "监测与预警系统",
"short_name": "术中压力监测系统",
"unit": "mmHg",
"anatomy_label": "监测区域",
"installer_id": "{请换成新的GUID}",
"labels": {
  "current_value": "当前压力",
  "heatmap": "风险热力图"
}
```

预警句子里的「拉钩」也可以改成你们现场的操作建议。保存后运行 `启动监测系统.bat` 就能看到新名称和单位。
