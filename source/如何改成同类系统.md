# 如何改成同类监测系统

改 `source/app/config.json` 即可换成另一套名称、阈值、文案和窗口，不必先改 `index.html`。

## 最短步骤

1. 用记事本或 VS Code 打开 `source/app/config.json`
2. 改 `branding`（名称）、`labels`（界面文字）、`baseline` / `alert`（算法）
3. 双击 `启动监测系统.bat` 预览（会自动运行 `apply_config.py`）
4. 确认无误后双击 `打包成EXE.bat`，再双击 `生成安装包.bat`

**同类新产品务必改 `branding.installer_id`**（换成新的 GUID），否则会和甲韵康跃抢同一个卸载项。可用 PowerShell 生成：

```powershell
[guid]::NewGuid().ToString()
```

填成 `{xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx}`。

## 改什么

| 区块 | 典型改法 |
|------|----------|
| `branding.app_name` / `short_name` / `logo_title` | 换成你的产品名。`short_name` 会变成 exe 和安装包文件名 |
| `branding.unit` | 肌电用 `μV`，压力可改 `mmHg`，温度可改 `℃` |
| `branding.anatomy_label` | 热力图中央文字，如「喉返神经」改成「监测部位」 |
| `labels.*` | 五张卡片、热力图、波形、串口提示的标题 |
| `alert.*_template` | 预警条句子。可用 `{risk}` `{safe}` `{baseline}` `{slope}` `{unit}` |
| `baseline.learn_count` | 学基线用多少个点 |
| `baseline.valid_min` / `valid_max` | 学习阶段合法信号范围 |
| `baseline.warn_multiplier` / `danger_multiplier` | 警戒、危险相对基线的倍数 |
| `alert.slope_threshold` | 趋势预判的斜率门槛 |
| `simulation.preset_sequence` | 「预设序列」播放的曲线 |
| `serial.baud_options` / `default_baud` | 设备波特率 |
| `window.*` | 窗口宽高和背景色 |
| `alarm.*` | 红/黄提示音频率和间隔 |

数字改完后，界面、声音、波形坐标会一起变。默认值与当前甲韵康跃产品一致。

## 不要改错的文件

- 日常请改 **`config.json`**，不要手改 `config.js`（启动时会覆盖）
- `index.html` 只在加新控件时才需要动
- 安装向导中文欢迎语在 `installer/甲韵康跃监测系统.iss` 的 `[Messages]`，需要时可再改两句

## 示例：改成「压力监测」

```json
"logo_title": "术中压力",
"logo_subtitle": "监测与预警系统",
"short_name": "术中压力监测系统",
"unit": "mmHg",
"anatomy_label": "监测区域",
"labels": {
  "current_value": "当前压力",
  "heatmap": "风险热力图",
  ...
}
```

保存后运行 `启动监测系统.bat` 即可看到新名称和单位。
