# 甲韵康跃 · 监测与预警系统

术中实时查看肌电信号（单位 μV），自动学习患者基线，并按阈值给出 **安全、警戒、危险和趋势预判**。数据可以来自手动输入、串口设备，或软件自带的模拟演示。

- 发放包版本：**1.0.3**（请先看这一份）
- 安装包 / 操作手册版本：**1.0.1**
- 系统要求：**Windows 10 / 11**
- 不需要安装 Python，不需要再打开原来的网页 `3.0.html`

> 本软件用于术中肌电趋势观察与预警提示，具体临床判断请结合现场操作规范。

## 3. 软件能做什么

本软件用于实时查看肌电信号（单位 μV），自动学习患者基线，并按阈值给出安全、警戒、危险和趋势预判。数据可以来自：

- **手动输入**
- **串口设备**
- **软件自带的模拟演示**

界面会同步更新：

- 当前值、斜率、风险等级、数据包、基线
- 预警条文字提示
- 热力图（喉返神经风险）
- 波形图
- 斜率图
- 警戒 / 危险时的声音预警

## 8. 拒绝访问 / ucrtbase.dll

如果安装到一半弹出错误，内容类似：**MoveFile 失败、错误代码 5、拒绝访问**，并且路径里有 `ucrtbase.dll`，按下面做，**不要点「跳过此文件」**。

1. 点「取消安装」。
2. 把已经打开的监测系统全部关掉。
3. 打开文件夹：`C:\Users\当前用户名\AppData\Local\`
4. 如果里面有「甲韵康跃监测系统」文件夹，整个删掉。
5. 用新的安装包（1.0.1）重新双击安装。

联想等电脑的用户名可能是 `lenovo`，完整路径就是：

`C:\Users\lenovo\AppData\Local\甲韵康跃监测系统`

## 9. 推荐操作流程

### 流程 A：演示（没有设备时）

1. 打开软件。默认就是「模拟」模式，波形会自己动。
2. 先看默认模拟数据是否刷新。
3. 用手动输入连续发送约 20 个稳定数值（例如都在 120～180），观察基线学习完成。
4. 再输入较高数值（例如 580、680），查看警戒和危险提示、声音预警是否出现。
5. 点「模拟」可回到自动演示；点「预设序列」可播放内置刺激曲线。

模拟会自动生成演示数据，每 **0.5 秒** 一条。

### 流程 B：手动输入真实或试验数据

1. 在顶部输入框填写肌电值，单位 μV。例如：`320`。建议范围 **100～800**。
2. 点「发送」，或在输入框里按回车。
3. 系统会自动切到「手动」模式，并停止自动生成数据。
4. 每次发送一条，当前值、斜率、风险等级、波形、热力图和声音都会立刻更新。
5. 输入框会自动清空，可连续录入。若要改回自动演示，点「模拟」。

手动输入时不必连接串口。

### 流程 C：连接串口设备

1. 把设备接到电脑，确认设备管理器里已经出现 COM 口。
2. 如正在学习基线或更换患者，可先点「重学」。
3. 点右上角「串口」。
4. 选择 COM 口。波特率默认 **9600**，也可选 **115200、57600** 等。
5. 点「连接」。状态会显示串口已连接，并等待设备数据。
6. 保持电极稳定，等顶部提示「基线已校准」后再进入正式监测。
7. 更换设备或结束时，点「断开」。

设备请按行发送数字，一行可以有一个或多个数值，例如：

```text
320
320,335,340
```

找不到端口时，先检查线缆和驱动，再点「刷新」。

## 10. 按钮一览

| 按钮 | 作用 |
|------|------|
| 发送 | 把输入框里的 μV 送进监测 |
| 串口 | 打开端口选择窗口 |
| 断开 | 断开串口 |
| 模拟 | 自动生成演示数据，每 0.5 秒一条 |
| 预设序列 | 按内置刺激曲线播放 |
| 暂停 | 停止处理新数据，可临时静音 |
| 重置 | 清空波形；已学到的基线会保留 |
| 重学 | 丢掉旧基线，重新学习当前患者 |

手动和串口不要同时作为正式数据源。进入手动后会停止模拟；连接串口后以设备数据为准。

## 11. 基线学习和预警规则

- 前 **20 个有效数据点** 会自动学习患者基线。
- 学习阶段请使用 **10～300 μV** 的稳定信号。
- 数值过大、过小或跳变剧烈时，会提示信号异常。
- 基线学成后：
  - **警戒线**约为基线的 **4 倍**
  - **危险线**约为基线的 **6 倍**
  - 并限制在安全范围内
- 未学成前，默认警戒约 **550 μV**、危险约 **650 μV**。
- 更换患者、更换电极或条件明显变化时，请点「重学」。

| 等级 | 界面表现 | 建议操作 |
|------|----------|----------|
| 安全 | 绿色，提示状态平稳 | 继续监测 |
| 趋势预判 | 蓝色，斜率上升过快（约大于 **8 μV/步**） | 建议提前减压 |
| 警戒 | 黄色，超过警戒阈值 | 留意操作，检查拉钩 |
| 紧急危险 | 红色，超过危险阈值，伴随声音 | 立即调整拉钩角度 |

预警条会用文字提示当前该怎么处理。每次新数据到达后，卡片、热力图、波形、斜率和声音会一起更新。

## 12. 常见问题

### 双击没有窗口

确认已经用安装包装过，并从桌面快捷方式打开。Windows 10/11 一般自带 WebView2。

### 串口列表是空的

检查 USB 线、设备电源和驱动。关掉占用该 COM 口的其他串口助手后，再点「刷新」。

### 基线一直学不成

学习阶段请输入或接入 10～300 μV 的稳定信号。

### 声音一直响

说明当前仍处于警戒或危险。可点「暂停」临时静音，或点「重置 / 重学」后重新监测。关闭软件也会停止提示音。

### 手动和串口能不能一起用

不要同时作为正式数据源。进入手动后会停止模拟；连接串口后以设备数据为准。

### 出现英文 PKG 报错

见 [第 7 节](#7-英文-pkg-报错)。

### 安装时提示拒绝访问 / ucrtbase.dll

见 [第 8 节](#8-拒绝访问--ucrtbasedll)。不要点「跳过此文件」。
