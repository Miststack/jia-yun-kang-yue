# 甲韵康跃 · 监测与预警系统

用于术中实时查看肌电信号（单位 μV），自动学习患者基线，并按阈值给出 **安全 / 警戒 / 危险 / 趋势预判**。数据可来自手动输入、串口设备，或软件自带的模拟演示。

当前发放包版本：**1.0.3**（Windows 10 / 11）

> 本软件用于肌电趋势观察与预警提示，具体临床判断请结合现场操作规范。

## 能做什么

- 实时显示当前肌电值、斜率、风险等级、数据包和基线
- 前 20 个有效数据点自动学习患者基线
- 警戒线约为基线 4 倍，危险线约为基线 6 倍（未学成前默认警戒约 550 μV、危险约 650 μV）
- 热力图、波形图、斜率图同步更新
- 警戒 / 危险时给出文字提示和声音预警
- 支持三种数据来源：模拟演示、手动输入、串口设备

## 安装

1. 如以前弹出过英文 PKG 报错，先删掉桌面上的「甲韵康跃监测系统」文件夹，并卸载开始菜单里的旧版本。
2. **双击** `甲韵康跃监测系统安装包.exe` 安装（不要解压，不要单独把 exe 拷到桌面运行）。
3. 勾选「创建桌面快捷方式」，完成后从桌面快捷方式打开。

安装时若出现 `ucrtbase.dll` / 拒绝访问：点「取消安装」，关掉已打开的监测窗口，删除 `C:\Users\当前用户名\AppData\Local\甲韵康跃监测系统`，再用本安装包重装。

## 使用方式

### 演示（没有设备）

打开软件后默认是「模拟」模式。也可用「预设序列」播放内置刺激曲线。

### 手动输入

在顶部输入框填写肌电值（建议 100～800 μV），点「发送」或按回车。系统会切到「手动」模式。

### 串口设备

1. 连接设备，确认设备管理器中已有 COM 口。
2. 点「串口」，选择端口（波特率默认 9600）。
3. 点「连接」，等提示「基线已校准」后再进入正式监测。
4. 设备按行发送数字，例如 `320` 或 `320,335,340`。

更换患者、更换电极或条件明显变化时，请点「重学」。

## 预警等级

| 等级 | 界面 | 建议 |
|------|------|------|
| 安全 | 绿色 | 继续监测 |
| 趋势预判 | 蓝色，斜率上升过快（约大于 8 μV/步） | 建议提前减压 |
| 警戒 | 黄色，超过警戒阈值 | 留意操作，检查拉钩 |
| 紧急危险 | 红色，超过危险阈值，伴随声音 | 立即调整拉钩角度 |

学习阶段请使用 10～300 μV 的稳定信号。声音一直响说明仍处于警戒或危险，可点「暂停」临时静音。
