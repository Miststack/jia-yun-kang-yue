# 甲韵康跃 · 监测与预警系统

用于术中实时查看肌电信号（单位 μV），自动学习患者基线，并按阈值给出 **安全 / 趋势预判 / 警戒 / 紧急危险**。面向喉返神经相关操作的肌电趋势观察，可配合拉钩调整给出提示。

当前发放包版本：**1.0.3**（Windows 10 / 11 桌面软件）

> 本软件用于肌电趋势观察与预警提示，具体临床判断请结合现场操作规范。

## 功能一览

### 1. 三种数据来源

| 模式 | 怎么用 | 说明 |
|------|--------|------|
| 模拟 | 打开软件后默认进入；也可点「模拟」 | 每 0.5 秒自动生成演示数据，适合没有设备时讲解和验收 |
| 预设序列 | 点「预设序列」 | 按内置刺激曲线播放，便于演示警戒、危险全过程 |
| 手动输入 | 顶部填 μV，点「发送」或按回车 | 建议范围 100～800；发送后自动切到手动模式，停止自动生成 |
| 串口设备 | 点「串口」→ 选 COM 口 → 连接 | 默认波特率 9600，也可选 115200、57600 等；连接后以设备数据为准 |

设备按行发送数字即可，一行可以有一个或多个数值，例如：

```text
320
320,335,340
```

手动输入时不必连接串口。不要把手动和串口同时当作正式数据源：进入手动后会停止模拟，连接串口后以设备数据为准。

### 2. 患者基线学习

- 前 **20 个有效数据点** 自动学习当前患者基线
- 学习阶段请使用 **10～300 μV** 的稳定信号
- 数值过大、过小或跳变剧烈时，会提示信号异常
- 学成后顶部提示「基线已校准」，再进入正式监测
- 更换患者、更换电极或条件明显变化时，点 **「重学」** 丢掉旧基线

### 3. 分级预警

学成后：

- **警戒线** ≈ 基线 × 4
- **危险线** ≈ 基线 × 6
- 阈值会限制在安全范围内

未学成前默认：警戒约 **550 μV**，危险约 **650 μV**。

| 等级 | 界面 | 触发条件 | 建议操作 |
|------|------|----------|----------|
| 安全 | 绿色 | 数值平稳、未越线 | 继续监测 |
| 趋势预判 | 蓝色 | 斜率上升过快（约大于 8 μV/步） | 建议提前减压 |
| 警戒 | 黄色，伴随声音 | 超过警戒阈值 | 留意操作，检查拉钩 |
| 紧急危险 | 红色，伴随声音 | 超过危险阈值 | 立即调整拉钩角度 |

预警条会用文字提示当前该怎么处理。声音一直响说明仍处于警戒或危险，可点「暂停」临时静音。

### 4. 实时可视化

- **数字卡片**：当前值、斜率、风险等级、数据包计数、基线
- **预警条**：当前风险与处理建议
- **热力图**：喉返神经风险分布
- **波形图**：肌电随时间变化
- **斜率图**：上升趋势是否过快

每次新数据到达后，卡片、热力图、波形、斜率和声音会一起更新。

### 5. 监测过程控制

| 按钮 | 作用 |
|------|------|
| 发送 | 把输入框里的 μV 送进监测；输入框随后自动清空，可连续录入 |
| 串口 | 打开端口选择窗口，可刷新端口列表 |
| 断开 | 断开串口 |
| 模拟 | 回到自动演示 |
| 预设序列 | 播放内置刺激曲线 |
| 暂停 | 停止处理新数据，可临时静音 |
| 重置 | 清空波形；**已学到的基线会保留** |
| 重学 | 丢掉旧基线，按当前患者重新学习 |

顶部状态圆点和文字会显示当前模式（模拟 / 手动 / 串口）以及风险状态。

### 6. 安装与部署

- 双击安装包即可，**不需要安装 Python**，也不需要再打开原来的网页
- 装完后从桌面快捷方式或开始菜单打开
- Windows 10 / 11 一般自带 WebView2

## 安装

1. 如以前弹出过英文 PKG 报错（`Could not load PyInstaller's embedded PKG archive`），先删掉桌面上的「甲韵康跃监测系统」文件夹，并卸载开始菜单里的旧版本。
2. **双击** `甲韵康跃监测系统安装包.exe` 安装（不要解压，不要单独把 exe 拷到桌面运行）。
3. 勾选「创建桌面快捷方式」，完成后从桌面快捷方式打开。

安装时若出现 `ucrtbase.dll` / 拒绝访问：点「取消安装」（不要点跳过），关掉已打开的监测窗口，删除 `C:\Users\当前用户名\AppData\Local\甲韵康跃监测系统`，再用本安装包重装。

## 推荐验收流程（无设备）

1. 打开软件，确认默认模拟波形在刷新。
2. 手动连续发送约 20 个稳定数值（例如都在 120～180），观察基线学习完成。
3. 再输入较高数值（例如 580、680），查看警戒 / 危险提示和声音是否出现。
4. 点「模拟」回到自动演示，或点「预设序列」播放内置曲线。

有设备时：先点「重学」（如需），再连串口，等「基线已校准」后进入正式监测。结束时先点「断开」，再关窗口。

## 常见问题

| 现象 | 处理 |
|------|------|
| 双击没有窗口 | 确认已用安装包装过，并从桌面快捷方式打开 |
| 串口列表是空的 | 检查 USB 线、设备电源和驱动；关掉占用该 COM 口的其他串口助手后点「刷新」 |
| 基线一直学不成 | 学习阶段请输入或接入 10～300 μV 的稳定信号 |
| 声音一直响 | 当前仍处于警戒或危险；可暂停静音，或重置 / 重学后重新监测 |
