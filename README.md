# 甲韵康跃 · 监测与预警系统

术中实时查看肌电信号（单位 μV），自动学习患者基线，并按阈值给出 **安全、警戒、危险和趋势预判**。数据可以来自手动输入、串口设备，或软件自带的模拟演示。

- 发放包版本：**1.0.3**（请先看这一份）
- 安装包 / 操作手册版本：**1.0.1**
- 系统要求：**Windows 10 / 11**
- 不需要安装 Python，不需要再打开原来的网页 `3.0.html`

> 本软件用于术中肌电趋势观察与预警提示，具体临床判断请结合现场操作规范。

## 功能一览

下面这些都是软件里已经有的能力，打开后可以直接用。

### 数据采集

- 三种正式数据源：**模拟演示、手动输入、串口设备**，顶部状态会显示当前模式
- **模拟模式**默认开启，每 0.5 秒一条数据；大约 10% 的点会故意抬高，方便演示越线
- **预设序列**按内置刺激曲线循环播放（约 320→730→300 μV），用于完整走一遍安全→警戒→危险→回落
- **手动输入**：顶部填 μV，点「发送」或按回车；发完自动清空，可连续录入
- 手动发送后自动退出模拟，避免演示数据和试验数据混在一起
- **串口**：列出本机 COM 口和设备描述，可刷新；默认 9600，可选 4800 / 19200 / 38400 / 57600 / 115200
- 设备按行发数字即可，一行可含多个值，例如 `320` 或 `320,335,340`
- 桌面版每 80ms 读取串口缓存，避免漏点
- 浏览器打开界面时，若系统支持 Web Serial 也可连设备；不支持时仍可手动输入
- 断开串口或网页串口失败后，自动退回模拟，并提示已切换
- 关掉监测窗口时自动断开串口，避免占用 COM 口
- 只接收大于 0 的数值；界面显示夹在 100～800 μV，防止波形冲出坐标

### 自适应基线

- 前 20 个有效点自动学习当前患者基线，卡片上显示 `8/20` 和百分比
- 学习范围 10～300 μV；过大、过小会提示「信号异常，请检查电极」，该点不计入
- 学成时去掉最高、最低各 2 个点再平均，减轻个别跳变影响
- 学成后卡片同时给出：基线、黄色警戒线、红色危险线
- 状态条提示「基线已校准」，窗口出现绿色光晕表示系统就绪
- 未学成前使用默认警戒 550 μV、危险 650 μV，仍可演示预警
- 学成后警戒 ≈ 基线×4（限制在 150～650），危险 ≈ 基线×6（限制在 250～800）
- **重学**：丢掉旧基线，换患者或换电极后重新校准；模拟下会先给若干稳定点，方便立刻开始学习

### 分级预警

- 四级：**安全（绿）→ 趋势预判（蓝）→ 警戒（黄）→ 紧急危险（红）**
- 先看有没有越危险线，再看警戒线，再看斜率，最后才判安全
- 斜率用最近 4 个点计算：`(当前 − 前第 4 点) / 3`，大于 8 μV/步给出趋势预判
- 预警条直接写出该怎么做，例如「立即调整拉钩角度」「留意操作，检查拉钩」「建议提前减压」
- 警戒：600 Hz，大约每秒一响
- 紧急危险：900 Hz，大约每 0.3 秒一响
- 安全、趋势预判不响；从危险回到安全会自动停声
- **暂停**会停止处理新数据并临时静音，按钮变成「继续」

### 实时可视化

- 五张数字卡片：当前肌电值、实时斜率、风险等级、已接收数据包、自适应基线
- 喉返神经 **8×8 热力图**，中央区域随风险变色，并标注「喉返神经」
- **波形图**最多 200 点：蓝线实时值，散点按上升速度着色（绿 / 橙 / 红），红色虚线向后外推 6 步
- **斜率柱状图**显示最近 30 步，颜色与上升快慢对应
- 顶部圆点随风险变绿 / 蓝 / 黄 / 红；暂停或等待时变灰
- 底栏实时日志：当前 μV、斜率、已收包数、基线
- 状态条区分：等待信号、校准中、系统就绪、监测中、已暂停

### 过程控制

- **暂停 / 继续**：临时冻结监测和声音，不改基线
- **重置**：清空波形和计数，**已学基线保留**，适合同一患者重新观察
- **重学**：基线和波形都清掉，适合换患者
- 串口占用时不能直接点「模拟」，需先断开，防止设备数据被演示数据盖住
- 串口弹窗可刷新端口；点空白处或按 Esc 关闭
- 窗口默认 1480×940，最小 1080×720；界面文字可复制
- `python main.py --debug` 可开调试

### 安装与部署

- Windows 10 / 11 双击安装包即可，**不需要 Python**，不需要打开原来的网页
- 中文「下一步 / 安装 / 完成」向导，可勾选桌面快捷方式，装完可立即打开
- 开始菜单带「使用说明」和卸载入口
- 安装到当前用户目录，一般不用管理员权限
- 安装前强制关掉旧窗口，避免文件被占用
- 不打包系统 `ucrtbase.dll`，减少联想等电脑上的「拒绝访问」
- 图表库离线内置，没网也能看波形

## 9. 推荐操作流程

### 流程 A：演示（没有设备时）

1. 打开软件。默认就是「模拟」模式，波形会自己动。
2. 先看默认模拟数据是否刷新。
3. 用手动输入连续发送约 20 个稳定数值（例如都在 120～180），观察基线学习完成。
4. 再输入较高数值（例如 580、680），查看警戒和危险提示、声音预警是否出现。
5. 点「模拟」可回到自动演示。再点一次顶栏按钮可进入「预设序列」，按内置刺激曲线循环播放（约 320→730→300 μV，每 0.5 秒一点）。

模拟会自动生成演示数据，每 **0.5 秒** 一条。约 10% 的点会故意抬高，便于看到警戒变化。

### 流程 B：手动输入真实或试验数据

1. 在顶部输入框填写肌电值，单位 μV。例如：`320`。建议范围 **100～800**。
2. 点「发送」，或在输入框里按回车。
3. 系统会自动切到「手动」模式，并停止自动生成数据。
4. 每次发送一条，当前值、斜率、风险等级、波形、热力图和声音都会立刻更新。
5. 输入框会自动清空，可连续录入。若要改回自动演示，点「模拟」。

手动输入时不必连接串口。

### 流程 C：连接串口设备

1. 把设备接到电脑，确认设备管理器里已经出现 COM 口。
2. 如正在学习基线或更换患者，可先点「重学」。
3. 点右上角「串口」。
4. 选择 COM 口。波特率默认 **9600**，也可选 **115200、57600、38400、19200、4800**。
5. 点「连接」。状态会显示串口已连接，并等待设备数据。
6. 保持电极稳定，等顶部提示「基线已校准」后再进入正式监测。
7. 更换设备或结束时，点「断开」。

设备请按行发送数字，一行可以有一个或多个数值，例如：

```text
320
320,335,340
```

找不到端口时，先检查线缆和驱动，再点「刷新」。

## 11. 基线学习和预警规则

### 基线怎么算

- 前 **20 个有效数据点** 自动学习。学习界面会显示进度（例如 `8/20`、百分比）。
- 有效范围：**10～300 μV**。超出则提示「信号异常，请检查电极」，该点不计入。
- 学成时去掉最高 2 个、最低 2 个，对其余 **16 个点取平均**（去极值均值），再四舍五入。
- 学成后卡片显示：基线、黄色警戒线、红色危险线；状态条提示「基线已校准」。
- 未学成前默认：警戒 **550 μV**、危险 **650 μV**。
- 更换患者、更换电极或条件明显变化时，点「重学」。重学在模拟模式下会先写入若干稳定点，方便重新校准。

学成后阈值：

- **警戒线** = 基线 × **4**
- **危险线** = 基线 × **6**
- 警戒限制在 **150～650 μV**
- 危险限制在 **250～800 μV**

显示层会把数值夹在 **100～800 μV**，避免波形超出坐标。

### 风险怎么判

斜率用最近 4 个点：`(当前值 − 前第 4 个值) / 3`，单位 μV/步。

判定顺序（先危险，再警戒，再趋势，最后安全）：

| 等级 | 界面 | 触发条件 | 声音 | 建议操作 |
|------|------|----------|------|----------|
| 紧急危险 | 红色 | 当前值 ≥ 危险线 | 900 Hz，约每 0.3 秒一响 | 立即调整拉钩角度 |
| 警戒 | 黄色 | 当前值 ≥ 警戒线 | 600 Hz，约每 1 秒一响 | 留意操作，检查拉钩 |
| 趋势预判 | 蓝色 | 斜率 > **8 μV/步** | 无 | 建议提前减压 |
| 安全 | 绿色 | 以上都不满足 | 无 | 继续监测 |

波形还会按逐步斜率着色：>8 红，>5 橙，其余绿；并向后外推 6 步。斜率图只显示最近 30 步。热力图为 8×8 网格，中央对应喉返神经区域，颜色随当前风险升高。波形最多保留 **200** 个点。

预警条会写出当前该怎么处理。每次新数据到达后，卡片、热力图、波形、斜率和声音一起更新。暂停会停止处理新数据并临时静音。

## 12. 常见问题

### 双击没有窗口

确认已经用安装包装过，并从桌面快捷方式打开。Windows 10/11 一般自带 WebView2。

### 串口列表是空的

检查 USB 线、设备电源和驱动。关掉占用该 COM 口的其他串口助手后，再点「刷新」。

### 基线一直学不成

学习阶段请输入或接入 10～300 μV 的稳定信号。

### 声音一直响

说明当前仍处于警戒或危险。可点「暂停」临时静音，或点「重置 / 重学」后重新监测。关闭软件也会停止提示音。

### 手动和串口能不能一起用

不要同时作为正式数据源。进入手动后会停止模拟；连接串口后以设备数据为准。

### 出现英文 PKG 报错

见 [第 7 节](#7-英文-pkg-报错)。

### 安装时提示拒绝访问 / ucrtbase.dll

见 [第 8 节](#8-拒绝访问--ucrtbasedll)。不要点「跳过此文件」。

2. 关闭窗口即可退出。

## 15. 源码

源码在仓库的 `source/` 目录，桌面程序结构如下：

```text
source/
  main.py                 Python 入口：开窗口、串口读写
  requirements.txt        pywebview / pyserial / pyinstaller
  app.ico                 软件图标
  启动监测系统.bat         本机直接运行（会自动装依赖）
  打包成EXE.bat           PyInstaller 打成 Windows 程序
  生成安装包.bat           用 Inno Setup 生成安装包
  甲韵康跃监测系统.spec     PyInstaller 配置（不打包系统 ucrtbase.dll）
  app/
    index.html            监测界面、基线、预警、波形、热力图
    chart.umd.min.js      图表库（离线）
  installer/
    甲韵康跃监测系统.iss    Inno Setup 安装向导脚本
    ChineseSimplified.isl 简体中文安装界面
```

技术组成：

- 界面：`app/index.html`（WebView2 里打开，不依赖在线网页）
- 桌面壳：`main.py` + `pywebview`（Edge Chromium / WebView2）
- 设备：`pyserial`，按行解析数字，支持 `320` 或 `320,335,340`
- 打包：PyInstaller onedir → `dist/甲韵康跃监测系统/`
- 安装包：Inno Setup 6 编译 `installer/甲韵康跃监测系统.iss`

### 从源码运行

需要本机已安装 Python 3，以及 Windows 10/11 自带的 WebView2。

```bat
cd source
启动监测系统.bat
```

或：

```bat
cd source
python -m pip install -r requirements.txt
python main.py
```

加 `--debug` 可打开调试：

```bat
python main.py --debug
```

### 重新打包 EXE

```bat
cd source
打包成EXE.bat
```

完成后程序在：

`source\dist\甲韵康跃监测系统\甲韵康跃监测系统.exe`

### 生成安装包

先安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)，再执行：

```bat
cd source
生成安装包.bat
```

完成后会在 `source\installer_output\` 生成 `甲韵康跃监测系统安装包.exe`，并复制一份到桌面。

### 源码里各文件负责什么

| 文件 | 职责 |
|------|------|
| `main.py` | 创建 1480×940 窗口，把串口 `list_ports / connect / disconnect / poll` 暴露给界面 |
| `app/index.html` | 全部监测逻辑：基线、分级预警、图表、热力图、声音、按钮、串口弹窗 |
| `app/chart.umd.min.js` | Chart.js，离线画波形和斜率图 |
| `甲韵康跃监测系统.spec` | PyInstaller；不打包 `ucrtbase.dll` 和 `api-ms-win-*`，避免对方电脑覆盖系统 DLL 失败 |
| `installer/甲韵康跃监测系统.iss` | 安装到用户目录、强制关掉旧窗口、排除 ucrtbase、创建桌面快捷方式 |

桌面软件每 **80ms** 向 Python 取一次串口缓存。若用浏览器直接打开 `index.html`，可走 Web Serial；没有网页串口时仍可手动输入。设备行解析与 Python 端相同：一行里的正数都会送进监测。

更细的代码说明见 [`source/README.md`](source/README.md)。
